OPCIÓN 1 — Sirve el config.yml como archivo estático correcto

Este es el fallo número uno en Vercel.

Vercel suele servir los YAML con tipo MIME incorrecto.
Solución: mueve tu config.yml a public/admin/config.yml y asegúrate de que se sube tal cual, no procesado por Astro.

Tu estructura debe ser:

public/
  admin/
    index.html
    config.yml


Y en tu /admin/index.html:

<script src="https://unpkg.com/decap-cms@^3.0.0/dist/decap-cms.js"></script>


Nada más.

Luego, asegúrate de que al visitar:
👉 https://astro-decap-cms-blog.vercel.app/admin/config.yml

se vea tu YAML plano, no el HTML del sitio.
Si ves HTML, Vercel está reescribiendo la ruta y debes agregar un vercel.json con:

{
  "rewrites": [
    { "source": "/admin/config.yml", "destination": "/admin/config.yml" }
  ]
}
